## 조사 범위와 신뢰도

이 문서는 원작의 구조를 파악하고 모바일 프로토타입으로 전환하기 위한 분석입니다. Steam 공식 소개를 기준점으로 삼고, 유튜브 검색 색인에 제공된 영상 설명·챕터, 데모 공략 및 공개 리뷰를 교차 검토했습니다.

**유튜브 영상 재생 화면과 전체 자막은 확보하지 못했습니다.** 직접 열기를 시도했으나 가져오기 오류·요청 제한이 발생했습니다. 따라서 영상 설명에 있는 챕터를 실제 장면 관찰로 간주하지 않습니다. 무해설 영상은 존재와 제목만 확인한 조사 후보입니다. 이 자료는 출처 기반의 설계 분석이며, 전체 영상을 시청한 완결된 영상 딥리서치는 아닙니다.

확인 수준은 다음과 같습니다.

| 표기 | 의미 |
| --- | --- |
| 공식 확인 | Steam의 개발사 제공 설명에서 확인 |
| 설명 확인 | 영상 검색 색인의 설명·챕터에서 확인 |
| 리뷰 의견 | 작성자의 경험·평가이며 사실의 전수 검증이 아님 |
| 설계 판단 | 위 자료를 참고해 이번 모바일 구현에 내린 선택 |

2025년 데모·앞서 해보기 자료와 2026년 정식 출시 리뷰는 구분해야 합니다. 2025년 자료의 직업 수, 밸런스와 전투 길이가 현재 버전에서도 동일하다고 단정하지 않았습니다. 공식 페이지에는 정식 출시일 2026-05-26, 앞서 해보기 2025-05-19가 표시됩니다. 가격·리뷰 비율은 변동값이므로 구현 판단의 기준 수치로 사용하지 않았습니다. [S1]

## 공식 핵심 구조

공식 소개는 서바이버 전투와 루팅 RPG의 결합을 강조합니다. 전투 중 경험치와 스킬로 빌드를 만들고, 드롭 장비를 로비에서 확인·장착·강화하며 상위 층에 도전합니다. 희귀 장비의 무작위 옵션, 자원 강화, 손으로 그린 다크 판타지 표현도 특징입니다. 장비에 따른 외형 변화는 공식 기능이나 이번 구현에서는 보류했습니다. [S1]

이 구조에서 이동과 회피는 순간의 판단, 축복 선택은 한 전투의 판단, 장비와 영구 성장은 여러 전투를 연결하는 판단입니다. **모바일에서 보존할 것은 이 세 판단의 연결**이라고 해석했습니다. 조작 버튼을 그대로 옮기는 것보다 손가락 아래에서 전장을 읽고, 짧은 중단 뒤에도 재도전 이유를 유지하는 것이 우선입니다. 이는 설계 판단입니다.

V1은 데모 첫인상 영상입니다. 색인의 챕터를 다음 조사 항목으로 변환했습니다. 아래 타임스탬프는 영상 설명에서 제공된 위치이며, 실제 장면의 시작·종료를 검증한 타임코드는 아닙니다.

V1의 제공 설명은 짧은 소개 형식이므로 장비 드롭 확률, 난도 곡선, 정확한 공격 동작은 여기서 추출할 수 없습니다. [V1]

V2는 무해설 데모 플레이 영상으로 검색되었습니다. 이는 HUD·보스 예고·인벤토리 동선 관찰에 적합한 **후속 시청 후보**이지, 현재 분석에서 전투 프레임이나 성능 수치의 근거는 아닙니다. [V2]

V3는 Gameplay 제목으로 검색되었습니다. 게시 시점과 빌드 버전을 직접 확인하지 못했으므로 ‘정식 출시 영상’으로 확정하지 않았습니다. [V3]

V4의 설명은 Diablo 계열의 느낌과 Darkest Dungeon을 연상시키는 미감을 언급합니다. 이는 진행자의 인상이며 공식 미술 분류가 아닙니다. 이를 참고해 낮은 채도, 석재 배경, 구별되는 발광 효과를 선택했습니다. [V4]

## 공개 리뷰 교차 분석

R1은 2025년 앞서 해보기 리뷰에서 전투 경험치, 무작위 3택 축복, 장비와 속성 성장의 연결을 설명합니다. 작성자는 일부 캐릭터의 축복 구성이 유사하다고 느꼈고 PC 컨트롤러 문제를 경험했다고 기록했습니다. 이는 해당 버전·환경에서의 의견이므로 현재 결함으로 일반화하지 않습니다. 모바일에서는 입력 취소·앱 전환·포커스 복원을 별도로 다룰 필요가 있다고 판단했습니다. [R1]

R2는 장비·스킬 조합의 깊이와 미술을 장점으로, 긴 세션과 일부 빌드의 우세, 초반 성장 체감을 마찰로 평가합니다. 이는 한 리뷰의 해석입니다. 이번 설계는 전투를 짧게 하면서 실제 공격 방식이 다른 직업과 수치가 보이는 선택지로 조합의 차이를 빨리 느끼게 하는 방향입니다. [R2]

R3은 데모 1층의 클리어 경험과 경험치 수집 관련 선택의 중요성을 설명합니다. 기록은 현재 버전의 평균 클리어 시간이나 전체 이용자의 경험을 뜻하지 않습니다. 모바일 설계에서는 경험치 흡입 반경을 기본 제공하고 수집 강화를 선택지로 남겨 이동 스트레스와 성장 선택을 조절했습니다. [R3]

C1에는 지속·투사체·범위 속성의 적용 대상과 키워드 표시를 묻는 이용자 질문이 있습니다. 보편적 불만의 빈도로 해석하지 않았습니다. 이번 UI는 ‘물리·화염·냉기·번개’, ‘근접·연쇄·주기’, ‘기본 공격·모든 공격’ 태그로 적용 범위를 표시합니다. [C1]

| 문제 가설 | 근거 | 설계 | 구현 위치 | 검증 방법 |
| --- | --- | --- | --- | --- |
| 세로 화면에서 버튼이 전장을 가린다 | 모바일 입력의 공간 제약, 설계 가설 | HUD 상단, 이동·회피 하단, 중심에 플레이어 | styles.css / app.js | 실기기 손가락 가림 확인 예정 |
| 짧은 이동 시간에 긴 전투를 마치기 어렵다 | R2의 세션 길이 의견 | 90초 웨이브 + 최대 60초 보스 | Game.duration / update | 엔진 시간·보스 단일 등장 테스트 |
| 공격 조작이 이동을 방해한다 | 설계 가설 | 자동 공격·조준, 수동 회피·폭발 | Game.attack / dash / nova | 직업별 엔진 시뮬레이션 |
| 스킬 효과·조합을 이해하기 어렵다 | C1의 키워드 질문 | 수치·속성·적용 범위가 있는 3택 | SKILLS / showChoices | 선택지 유효성·상한·정지 테스트 |
| 파밍 보상이 로비에서 묻힌다 | S1, V1의 루프 | 결과창 비교·장착, 장비함·강화 분리 | finishGame / showGear | 장비 수치·정산 테스트 |
| 앱 전환으로 플레이를 잃는다 | 모바일 환경의 중단, 설계 가설 | 5초 저장, 전환 시 정지, 이어하기 | save / visibilitychange | 스냅샷 복원 테스트, 실기기 예정 |
| 많은 적·입자가 성능을 떨어뜨린다 | 설계 가설 | 적 약 100 제한, 입자 제한, DPR 최대 2, 절전 모드 | Game.update / draw / resize | 객체 수 제한 테스트, FPS 실측 예정 |
| 실패만 반복하면 성장 동기가 약해진다 | R1/R2의 성장 관련 의견 | 실패 보상·영구 강화, 다음 층 해금 | grantRewards / UPGRADES | 패배 보존·중복 정산 방지 테스트 |

90초와 60초는 원작의 수치가 아닌 이번 프로토타입의 초기 튜닝값입니다. 짧은 모드는 빌드 선택 횟수도 감소하므로 실제 이용자 테스트에서 레벨업 빈도와 체감 난도를 같이 조정해야 합니다.

| 요소 | 초기 설계 |

| 기사 | HP 140, 근접 100 반경, 넓은 베기 |

| 층 난도 | 적 체력·피해·출현률과 보스 체력 증가 |
| 패배 | 획득 장비·전투 파편 유지, 추가 15파편 |

파편은 단일 성장 자원입니다. 적 처치 수를 보상 계산으로 직접 연결하여 초반에도 강화 기회를 제공합니다. 여러 종류의 통화, 재료, 장비 옵션 체계를 넣지 않아 비교 비용을 줄였습니다. 기본 공격력 강화는 축복 피해 강화와 결합되지만 공격 속도 축복은 기본 공격에만 적용됩니다. 장비를 바꾸면 다음 전투 시작 시 반영됩니다.

## 후속 영상 딥리서치 프로토콜

다음은 실제 시청·자막 확보 후 채울 검증 항목이며 현재 완료한 관찰이 아닙니다.

1. 각 영상의 원본 게시일, 데모/앞서 해보기/정식 버전, 패치 버전을 확인한다.
2. 0~2분: 첫 조작, 첫 적, 첫 경험치, 첫 선택까지 실제 시간을 기록한다.
3. 중반 3구간: 화면 내 적 수, HUD 크기, 위험 예고, 획득 효과를 샘플링한다.
4. 보스전: 예고부터 피해 발생까지 시간을 재고 조작 여유를 확인한다.
5. 결과·로비: 재도전까지 클릭 수, 장비 비교 정보, 해금 안내를 기록한다.
6. 리뷰 발언은 타임코드와 짧은 원문·한국어 요약을 연결하고 긍정·부정·개선 제안을 구분한다.
7. 동일 주장은 독립된 영상 또는 공식 문서로 교차 검증한다. 버전 차이는 별도 기록한다.

## 범위와 다음 개발 과제

완료한 것은 모바일 웹 게임의 전체 반복 루프입니다. 원작을 그대로 재현한 상품 수준의 이식판은 아닙니다. 네이티브 패키징, 서버 저장, 계정, 전체 원작 콘텐츠, 장비 외형, 장애물 충돌, 콘텐츠별 완성도 있는 사운드와 아트는 다음 단계입니다.

개발 우선순위는 실제 기기 입력·전투 안정성 → 초반 성장과 보스 난도 → 영상 장면 검증 → 장비·직업 콘텐츠 확대 → 네이티브 패키징입니다. 측정하지 않은 FPS·기기 호환성·유지율 수치를 실적처럼 제시하지 않습니다.
