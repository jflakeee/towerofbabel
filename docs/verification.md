6. 보스전 제한 시간.
7. 승리/패배 보상, 다음 층 해금, 보상 중복 지급 방지.
8. 전투 위치·장비·선택지·쿨다운의 저장 복원.
9. 손상된 프로필 값과 존재하지 않는 장착 아이템 정리.
10. 영구 강화와 장비의 시작 능력치 반영.
11. 3개 직업의 전체 전투 시뮬레이션, 유한 수치와 객체 수 제한.
12. 업데이트 루프 바깥에서 수동 폭발로 보스 처치 시 승리 상태 반영.
13. 영구 강화가 없는 각 직업의 첫 층 클리어 경로 확인.

시뮬레이션의 장시간 검증은 영웅 체력을 크게 설정해 보스 단계까지 진행합니다. 이는 난이도·실제 승률·조작 품질을 검증하는 사용자 테스트가 아닙니다.

최종 자동 테스트 결과: **15개 통과, 실패 0개**. 구문 검사와 정적 빌드도 통과했습니다.

## 배포·오프라인·손상 복구 검증 (2026-10-11 후속)

- 80개 자동 테스트 통과. 생산 빌드 검사도 테스트에 포함한다.
- 원본과 백업이 모두 손상됐거나 더 새로운 저장 버전이면 기본 프로필로 덮어쓰지 않고 저장 보호 화면을 연다. 손상 원본 내보내기와 유효한 백업 선택·교체를 제공한다.
- 손상 복구 시 원본 두 개를 별도 보관한 후 교체한다. 저장 공간 부족·다른 탭의 복구 요청에서 원본이 유지되는지 검사했다.
- 전투 중 복구 백업을 불러오면 기존 전투를 종료하고 로비에서 불러온 저장의 이어하기를 선택하게 한다. 기존 전투가 가져온 프로필을 다시 덮어쓰지 않는 DOM 흐름을 검사했다.
- 읽을 수 없는 진행 중 전투는 자동으로 삭제하지 않는다. 새 도전을 선택할 때 백업·전투 기록 삭제의 결과를 안내하고 명시적으로 선택하게 한다.
- 정상 숫자로 보이지만 지나치게 큰 속도·충돌 반경·탄환 이동값과 과도한 객체 수를 복원에서 거부해 시뮬레이션 정지를 예방한다.
- 시작 화면·스타일·모든 모듈에 같은 빌드 식별자를 사용하는 파일명을 적용하고 모듈 참조와 캐시 목록을 검사했다.
- 서비스 워커 설치는 모든 파일의 SHA-256을 검증한다. 중간 다운로드 실패·다른 빌드 파일 혼입 시 새 캐시를 폐기하고 이전 캐시를 보존한다.
- 업데이트는 설치만으로 현재 전투를 재시작하지 않는다. 로비 설정의 저장 후 적용, 또는 모든 이전 탭이 종료된 뒤 활성화한다. 다른 탭의 업데이트로 컨트롤러가 바뀌어도 작성자 탭은 먼저 저장한다.
- 캐시 누락 시 원래 빌드와 같은 바이트만 복구하며, 다른 버전이면 실행을 거부한다. 로드 실패 화면에는 새 버전 적용을 재시도하는 동작을 제공한다.
- 현재 페이지와 활성 캐시의 빌드·전체 파일을 확인한 후에만 ‘오프라인 준비 완료’를 표시한다. 캐시 정리는 같은 앱 경로에 한정한다.
- 180/192/512 PNG 설치 아이콘 및 iOS 홈 화면 아이콘 연결, 실제 PNG 크기·빌드 포함 여부를 검사했다.

서비스 워커 검증은 Node의 격리된 이벤트·Cache API 모형이다. iOS/Android 브라우저의 실제 설치·캐시 제거 정책·터치·FPS·발열을 검증한 것은 아니다. 원작의 전체 영상·정확한 콘텐츠 대조도 아직 미완료다.
