# 검증 기록

검증일: 2026-10-11

## 수행한 검증

- `npm run check`: engine.js, app.js, sw.js JavaScript 구문 검사.
- `npm test`: Node 내장 테스트 러너, 전투·성장·저장 모델 검증.
- `npm run build`: 외부 패키지 설치 없이 dist에 정적 자원 생성.

자동 테스트 항목:

1. 3개 직업의 이동 경계와 대각선 속도 정규화.
2. 레벨업 중 시간 정지, 유효한 선택만 수락, 연속 레벨업 정산.
3. 최대 축복 제외와 새로고침 횟수 제한.
4. 회피 무적과 쿨다운.
5. 90초 보스의 1회 등장, 보스 처치 승리와 희귀 보상.
6. 보스전 제한 시간.
7. 승리/패배 보상, 다음 층 해금, 보상 중복 지급 방지.
8. 전투 위치·장비·선택지·쿨다운의 저장 복원.
9. 손상된 프로필 값과 존재하지 않는 장착 아이템 정리.
10. 영구 강화와 장비의 시작 능력치 반영.
11. 3개 직업의 전체 전투 시뮬레이션, 유한 수치와 객체 수 제한.
12. 업데이트 루프 바깥에서 수동 폭발로 보스 처치 시 승리 상태 반영.
13. 영구 강화가 없는 각 직업의 첫 층 클리어 경로 확인.

시뮬레이션의 장시간 검증은 영웅 체력을 크게 설정해 보스 단계까지 진행합니다. 이는 난이도·실제 승률·조작 품질을 검증하는 사용자 테스트가 아닙니다.

최종 자동 테스트 결과: **15개 통과, 실패 0개**. 구문 검사와 정적 빌드도 통과했습니다.

## 배포 설정

소스 저장소는 `jflakeee/towerofbabel`, 기본 브랜치는 `main`입니다. GitHub Actions 워크플로는 구문 검사·15개 엔진 테스트·정적 빌드 후 Pages 배포를 수행하도록 구성했습니다. 저장소 Settings → Pages에서 Source를 GitHub Actions로 선택해야 합니다. 실제 실행·배포 결과는 저장소 Actions에서 확인하세요.

## 수행하지 못한 검증

현재 실행 환경에서 지정된 브라우저 제어 기능을 사용할 수 없어 브라우저 시각·터치 검증을 실행하지 않았습니다. iOS Safari / Android Chrome 실기기, 홈 화면 설치, 오프라인 새로고침, 실제 FPS와 오디오 재생은 미검증입니다. 외부 서버 배포 성공 여부는 별도 원격 결과로 확인해야 합니다.

수동 QA 체크:

- 360×640, 390×844, 430×932 및 가로 화면에서 로비·모달·HUD 확인.
- 이동 중 다른 손가락으로 회피·폭발, 포인터 취소 후 이동 정지.
- 노치·홈 인디케이터에서 버튼이 가려지지 않는지 확인.
- 배경 전환·전화·잠금 이후 일시정지 상태와 저장 확인.
- 전투 중 새로고침 후 이어하기와 축복 선택 복원.
- 승리·패배 후 새로고침해 보상이 한 번만 지급되는지 확인.
- 오프라인에서 설치된 페이지 실행, 저장, 재실행.
- 업데이트 후 새 JS와 엔진 파일이 같은 버전으로 로드되는지 확인.
- 절전·높음 화질에서 100마리 전투 프레임 시간 측정.

## 전투 위험 표시 개선

- 체력 25% 이하에서 화면 가장자리와 HUD에 경고 표시.
- 보스 제한 15초 이하에서 시간과 안내 문구 강조.
- 사용 가능한 회피·폭발 버튼의 테두리와 준비 문구 표시. 접근성 이름에 재사용 대기 시간 반영.
- 경고는 종료 상태에서 제거하고, 축복 선택 중에는 현재 위험 상태를 유지.
- 실기기 시각·터치 검증은 미완료.

## 이동 입력 전용 자동 전투 1차

- 8방향 터치 키, 다중 포인터 입력 합성·정규화와 개별 해제. 키보드 전투 조작과 수동 스킬 버튼 제거.
- 축복 후보 자동 평가·연속 레벨업 처리·저장 복원·결과 선택 이유 기록.
- 위험 예고 및 접근 탄환·근접 위험에 따른 자동 회피, 적 밀집·보스 근접 시 자동 폭발.
- 설정의 균형·생존·공격·파밍 성향. 앱 복귀 후 방향키 입력 전까지 정지.
- 자동화 및 입력 모델 테스트 7개 추가. 총 22개 통과, 구문 검사·빌드 통과.
- 각 직업의 자동화 시뮬레이션이 승리/패배 종료까지 진행됨을 확인. 자동 선택의 전역 최적성이나 승리 보장은 검증하지 않음.
- 실기기 방향키 터치·가림·FPS·앱 복귀 시각 검증 미완료. 유료 재설정과 장비 옵션 변경은 미구현.
