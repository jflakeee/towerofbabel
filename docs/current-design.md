# 현재 모바일 설계와 완료 조건

검토일: 2026-10-13 KST. 코드 기준: b44d64ea381272404f48109cf04450581df689c2.

사용자의 최신 요구를 정리한 현재 기준이다. 과거 문서의 수동 방향키·층별 축복 초기화·보스 처치 후 결과 강제 표시·다음 단계 수동 시작 설명보다 우선한다. 아래의 ‘코드 대응 확인’은 실기기 품질이나 원작 완전 동일성을 뜻하지 않는다.

## 현재 플레이 규칙

1. 전투 이동은 화면 어디서든 시작하는 가상 조이스틱으로 조작한다. 최신 손가락이 입력을 소유하며 이전 손가락 해제는 이동을 취소하지 않는다. 공격·조준·회피·폭발·스킬 선택·포인트 수집은 자동이다.
2. 보스 처치 시 바닥의 남은 경험치 포인트 자동 회수·레벨업 자동 선택·보상 정산·더 좋은 장비 자동 장착·다음 단계 저장을 함께 확정한 뒤 바로 전투를 이어간다. 장착 잠금과 보유 아이템은 유지한다. 정산 시 장비 추천은 해당 전투에 저장된 성향·옵션 우선순위를 사용하며 로비에서 바꾼 빌드는 새 도전에 적용한다. 결과 화면에서 수동 장착하지 않는다.
3. 연속 단계에서는 전체 스킬 레벨·캐릭터 레벨·경험치·체력·쿨다운과 장비 상태를 유지한다. 장비 변경분만 능력치에 반영한다. 로비에서 **새 도전**을 시작할 때만 전투 성장 상태를 새로 만든다.
4. 상단 ‘전투 결과 확인’은 전투를 일시정지한다. 결과의 ‘전투 계속’으로 돌아가거나 ‘전투 종료 · 로비로’로 현재 획득품까지 정산한다. 패배 시에도 획득품을 정산한다.
5. 탑 1~5층 뒤 혼돈 1~20단계로 연결한다. 혼돈 20단계는 반복한다. 혼돈은 5개씩 해금하며 현재 선택·최고 해금·확인된 최고 정복을 별도로 보존한다. 최고 정복은 승리 시에만 갱신하며 최근 기록이 삭제되어도 유지한다. 구버전은 남아 있는 명시적 혼돈 승리 기록만 복원하고 선택·해금 단계로 추정하지 않는다. 해금한 이전 단계는 로비에서 선택 가능하다. 저장된 전투의 난이도·모드·진행 순서는 연속 단계에서도 유지하며, 로비에서 바꾼 도전 설정은 새 도전에 적용한다.
6. 새 도전에는 경험치 포인트 8개를 배치한다. 3층 정복 후에는 시작 스킬 1개를 설정한 자동 정책으로 지급한다. 둘 다 이어하기나 단계 전환에서 재지급하지 않는다. 수량과 후보 풀은 모바일 독립 조정값이다.
7. 모든 사용 가능 스킬이 최대 레벨이면 이후 레벨업마다 체력 25를 자동 회복한다(최대 체력 한도). 한꺼번에 오른 레벨도 각각 반영하며 처리한 레벨을 다시 지급하지 않는다. 기본 회복은 전투 시간 3초마다 최대 체력 1%다. 전설 방어구 회복과 별도로 적용하고 회복 주기를 단계·저장 복원에 유지한다.
8. 유료 강화·옵션 변경·재설정·분해 복원·소켓·연금술은 결과와 비용을 미리 보여 주고 확정한 뒤 적용한다. 무료 설정·프리셋·장비 변경도 저장 실패 시 롤백한다. 연속 단계에서 강화 예산을 다시 소비하지 않는다.
9. 최근 20개 단계의 전체 스킬과 단계별 선택 로그를 구분해 기록한다. 기록을 다음 빌드로 가져오면 선택 우선순위가 바뀌며 스킬이 미리 지급되지는 않는다. 옛 기록에 없는 정보는 복원했다고 주장하지 않는다.
10. 앱 이탈 시 정지·저장하고 복귀 후 이동 입력으로 재개한다. 저장 실패 시 정지·재시도·백업을 제공한다. 승리 복구 백업에도 다음 단계와 성장 상태를 포함한다. 설정 하단에 실제 빌드 시각을 표시한다.
