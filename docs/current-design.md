# 현재 모바일 설계와 완료 조건

검토일: 2026-10-14 KST. 코드 기준: 투기장 무료 미리보기 UI 반영.

사용자의 최신 요구를 정리한 현재 기준이다. 과거 문서의 수동 방향키·층별 축복 초기화·보스 처치 후 결과 강제 표시·다음 단계 수동 시작 설명보다 우선한다. 아래의 ‘코드 대응 확인’은 실기기 품질이나 원작 완전 동일성을 뜻하지 않는다.

## 현재 플레이 규칙

1. 전투 이동은 화면 어디서든 시작하는 가상 조이스틱으로 조작한다. 최신 손가락이 입력을 소유하며 이전 손가락 해제는 이동을 취소하지 않는다. 공격·조준·회피·폭발·스킬 선택·포인트 수집은 자동이다.
2. 보스 처치 시 바닥의 남은 경험치 포인트 자동 회수·레벨업 자동 선택·보상 정산·더 좋은 장비 자동 장착·다음 단계 저장을 함께 확정한 뒤 바로 전투를 이어간다. 장착 잠금과 보유 아이템은 유지한다. 정산 시 장비 추천은 해당 전투에 저장된 성향·옵션 우선순위를 사용하며 로비에서 바꾼 빌드는 새 도전에 적용한다. 결과 화면에서 수동 장착하지 않는다.
3. 연속 단계에서는 전체 스킬 레벨·캐릭터 레벨·경험치·체력·쿨다운과 장비 상태를 유지한다. 장비 변경분만 능력치에 반영한다. 로비에서 **새 도전**을 시작할 때만 전투 성장 상태를 새로 만든다.
4. 상단 ‘전투 결과 확인’은 전투를 일시정지한다. 결과의 ‘전투 계속’으로 돌아가거나 ‘전투 종료 · 로비로’로 현재 획득품까지 정산한다. 패배 시에도 획득품을 정산한다.
5. 탑 1~5층 뒤 혼돈 1~20단계로 연결한다. 혼돈 20단계는 반복한다. 혼돈은 5개씩 해금하며 현재 선택·최고 해금·확인된 최고 정복을 별도로 보존한다. 최고 정복은 승리 시에만 갱신하며 최근 기록이 삭제되어도 유지한다. 구버전은 남아 있는 명시적 혼돈 승리 기록만 복원하고 선택·해금 단계로 추정하지 않는다. 해금한 이전 단계는 로비에서 선택 가능하다. 저장된 전투의 난이도·모드·진행 순서는 연속 단계에서도 유지하며, 로비에서 바꾼 도전 설정은 새 도전에 적용한다.
6. 새 도전에는 경험치 포인트 8개를 배치한다. 3층 정복 후에는 시작 스킬 1개를 설정한 자동 정책으로 지급한다. 둘 다 이어하기나 단계 전환에서 재지급하지 않는다. 수량과 후보 풀은 모바일 독립 조정값이다.
7. 모든 사용 가능 스킬이 최대 레벨이면 이후 레벨업마다 체력 25를 자동 회복한다(최대 체력 한도). 한꺼번에 오른 레벨도 각각 반영하며 처리한 레벨을 다시 지급하지 않는다. 기본 회복은 전투 시간 3초마다 최대 체력 1%다. 전설 방어구 회복과 별도로 적용하고 회복 주기를 단계·저장 복원에 유지한다.
8. 유료 강화·옵션 변경·재설정·분해 복원·소켓·연금술은 결과와 비용을 미리 보여 주고 확정한 뒤 적용한다. 무료 설정·프리셋·장비 변경도 저장 실패 시 롤백한다. 연속 단계에서 강화 예산을 다시 소비하지 않는다.
9. 최근 20개 단계의 전체 스킬과 단계별 선택 로그를 구분해 기록한다. 기록을 다음 빌드로 가져오면 선택 우선순위가 바뀌며 스킬이 미리 지급되지는 않는다. 옛 기록에 없는 정보는 복원했다고 주장하지 않는다.
10. 앱 이탈 시 정지·저장하고 복귀 후 이동 입력으로 재개한다. 저장 실패 시 정지·재시도·백업을 제공한다. 승리 복구 백업에도 다음 단계와 성장 상태를 포함한다. 설정 하단에 실제 빌드 시각을 표시한다.

## 복수 보스 전투 기반 — 2026-10-14

## 투기장 무료 미리보기 — 2026-10-14

로비의 ‘투기장 전투 미리보기’에서 안내를 확인한 뒤 무료로 시작한다. 선택한 영웅·장착 장비·영구 강화·자동 선택 설정을 복제하고 레벨 1부터 시작한다. 두 보스와 잡몹을 상대로 최대 5분 동안 이동만 조작한다. 적 구성과 능력치는 모바일 시험용이다.

일시정지·계속·종료·종료 후 재도전과 별도 진단 JSON 내보내기를 제공한다. 미리보기의 성장·획득품·승패는 프로필에 저장하거나 정산하지 않는다. 자동 저장·앱 이탈·승리·패배·종료 시에도 기존 재화·장비·저장된 일반 전투를 유지한다. 일시정지는 메모리 안에서만 유지하며 새로고침·앱 완전 종료 후에는 미리보기를 이어갈 수 없다. 기존 일반 전투 이어하기는 보존한다.

검증: DOM·Canvas 모형에서 시작 취소, 자동 저장 주기를 넘긴 전투, 앱 이탈·복귀, 일시정지·계속, 수동 종료, 승리·패배·재도전, 진단 내보내기, 원래 전투 이어하기를 검사했다. 미리보기 전후 전체 저장소 값이 동일함을 확인했다. 전체 154개 자동 검사·정적 검사·빌드 통과. 실제 모바일 기기의 조작·렌더링·지속 성능은 미검증이다.

이 기능은 정식 투기장의 완료가 아니다. 입장 비용·전용 재화·보상 수량·주얼 규칙은 확인된 명세 확보 후 별도로 구현한다.


## 투기장 복수 보스 표시 — 2026-10-14

투기장에서는 두 보스의 체력 비율·분노 상태를 각각 표시한다. 전장의 보스 표식, HUD, 화면 밖 방향 안내에 같은 1·2번을 사용하고 한 보스를 처치해도 생존 보스의 번호를 변경하지 않는다. 두 방향 안내가 겹치면 세로로 분리하고 화면 안에 들어오거나 처치되면 해당 안내만 숨긴다. 체력 막대는 나란히 배치해 HUD 높이 증가를 줄인다. 일반 탑·혼돈은 기존 단일 보스 표시를 유지한다.

DOM·Canvas 모형에서 서로 다른 체력, 좌우 화면 밖 배치, 같은 방향의 안내 분리, 양쪽 처치 순서, 화면 진입, 일반 전투 복귀 시 보조 HUD 제거를 검사했다. 전체 자동 검사 154개와 구문 검사·빌드 통과. 실제 모바일 화면 가독성·터치 수용 검증은 별도로 남아 있다.


## 브라우저 확인과 화면 접근성 보완 — 2026-10-14

배포 사이트를 클라우드 Chrome에서 실제로 열어 로비 → 투기장 안내 → 전투 → 일시정지 결과 흐름과 Canvas 렌더링을 확인했다. 전투 화면에 가려진 로비·상단 설정이 접근성 트리에 남고 포커스가 로비 진입 버튼에 머무는 문제를 발견했다.

## 앱 복귀·저장 실패 안내 — 2026-10-14

기존 전투 도움말의 상시 숨김 스타일 때문에 일시정지·저장 완료 메시지까지 보이지 않는 문제를 수정했다. 일시정지 알림만 중앙에 명확히 표시하고 상태 알림으로 읽히게 한다. 알림은 이동 터치를 가로채지 않으며 터치 재개·결과 화면의 계속·다음 단계 시작 때 제거한다. 숨겨진 문서에서 계속을 요청하면 정지를 유지한다. 저장 실패 시에는 재시도/백업 안내, 재시도 성공 시에는 터치 재개 안내를 구분한다.

자동 검증은 앱 이탈 후 시간 정지, 일반/미리보기 계속의 안내 제거, 저장 실패 문구 보존·재시도 성공·이동 재개를 포함한다. 전체 154개 검사·구문 검사·빌드 통과. 실제 iOS/Android 앱 전환·터치 수용 검증은 별도로 남는다.


## 화면 회전 중 전투 보호 — 2026-10-14

## 투기장 미리보기 최고 정복 기준 — 2026-10-14

무료 미리보기의 난도 기준을 로비에서 선택한 층·혼돈 단계에서 `chaosBestCleared`로 변경했다. 시작할 때 기록을 고정하며 결과와 진단 JSON에도 남긴다. 선택한 전역 난이도(일반/어려움/악몽)는 계속 적용한다. 정복 기록이 0이면 기본 단계 1을 사용하되 정복 기록 자체를 1로 올리지 않는다.

공식 1.1.0의 최고 정복 기준만 반영한 모바일 시험 규칙이다. 전장·적 기본값은 1층으로 고정하고 기존 혼돈 배율 `1+(max(1,최고 정복)-1)×0.08`을 사용한다. 층 순환으로 높은 기록에서 적이 약해지는 것을 방지한다. 원작의 정확한 배율·보스 구성 재현이나 정식 투기장 보상 구현을 뜻하지 않는다. 로비에서 선택한 층·모드·혼돈 해금 범위와 기존 저장된 전투는 바꾸지 않는다.

최고 정복/선택/해금 구분, 기록 0·1·5·6·10·11·20 경계, 기존 일반 전투, 진입 시점 값의 복원, 모순된 저장 거절, 안내·결과·진단 표시와 저장 격리를 자동 검사했다. 구버전 내부 투기장 스냅샷은 원래 난도를 유지한다. 실기기 수용과 입장 비용·전용 보상은 미완료다.
