## 이번 보완의 검증

90개 자동 검사 통과. DOM 모형으로 장비 강화/소켓/영구 강화/분해의 미리보기·취소·확정, 분해 복원 원본/재화, 중복 확정, 성능 화면과 전투 기록 연결을 검사했다. 저장 실패에 따른 무료 편집 롤백, 자동 장착 전후 이력의 저장 복원, 동점 우선순위, 60FPS 계산·긴 프레임·중단 시간 제외를 추가 검증했다. 구문 검사·정적 생산 빌드도 통과했다.

진단은 전투 실행 구간만 측정한다. 이어하기는 새 구간이며 앱 백그라운드 시간은 제외한다. 95백분위는 1ms 구간의 고정 크기 히스토그램으로 계산하고 1000ms 이상은 `1000+`로 표시한다. 기기 식별자·외부 전송은 없고 온도/배터리를 측정하지 않는다. 측정 기능 자체가 실제 휴대폰의 성능 기준 통과를 의미하지 않는다.

## 실기기 확인 순서

1. 설정에서 최근 빌드 시각과 오프라인 준비 완료 확인.
2. 전투 화면의 좌상/우상/좌하/우하에서 드래그. 왼손을 댄 채 오른손으로 전환하고 왼손을 떼도 오른쪽 입력이 유지되는지 확인.
3. 앱 전환·화면 회전·손 떼기 후 자동 이동이 남지 않는지 확인.
4. 수문장 클리어 후 장비 전후 기록·잠근 부위·다음 층 적용 확인.
5. 20분 이상 반복 전투 후 설정 → 플레이 성능 확인 → 진단 기록 내보내기. 평균뿐 아니라 95백분위 지연과 50ms 초과 횟수 검토.
6. 홈 화면 설치·오프라인 재실행·전투 이어하기·새 버전 적용 후 저장 보존 확인.

## 전투 판정 보완 — 2026-10-12 후속

탄환은 프레임 도착점만 검사하던 방식에서 이동 선분의 첫 충돌 시각을 검사하도록 수정했다. 플레이어·적 탄환 모두 고속 통과를 방지하며 벽보다 먼저 맞은 적에게만 피해를 준다. 관통 탄환은 한 프레임 안에서도 가까운 적부터 처리하고 같은 적 중복 명중을 막는다. 남은 수명만큼만 이동해 수명 밖의 적을 공격하지 않는다. 수문장 처치로 승리가 확정되면 후속 탄환 피해와 추가 처치 보상을 차단한다. 오래된 선택 후보에 남아 있더라도 직업 제한·축복 상한을 재검사한다.

추가 회귀 검사 7개 포함 **97개 통과**. 기존 3직업 첫 층 승리, 최종 난이도·혼돈 보스 및 저장 복원 검사도 통과했다. 이 결과는 원작 동일성 또는 실제 휴대폰 판정 검증을 의미하지 않는다.

## 포인트 드롭 표시 복구와 종료 자동 장착

적 처치 시 생성되는 경험치 포인트의 Canvas 표시 누락을 복구했다. 일반 포인트는 청록색, 6포인트 이상 묶음은 금색으로 표시하고 근처에서 자동 수집한다. 피해 숫자·이펙트 불투명도 설정과 별개로 항상 표시한다. 포인트 생성·거리 밖 보존·저장 복원·수집 1회와 실제 렌더 호출을 검사했다.

모든 승리·패배 종료 시 획득품을 포함해 더 좋은 장비를 자동 장착한다. 이전 저장의 자동 장착 끄기 값은 적용하지 않으며 UI 토글을 제거했다. 잠근 부위·더 높은 점수의 기존 장비·이전 장비 복원은 유지한다. 자동 검사 **98개 통과**. 실기기 시각 검증은 미완료다.

## 도전 시작 저장 보호 — 2026-10-12 후속

새 전투 생성·자동 강화 예산 사용·다음 층 선택·전투 스냅샷을 한 초안에서 처리하고 한 번의 저장 성공 후 화면을 전환한다. 기존에는 자동 강화만 저장된 뒤 전투 저장이 실패할 수 있었으나, 이제 실패하면 파편·강화·선택 층·진행 중 전투가 시작 전 상태를 유지한다. 저장된 전투가 남아 있으면 새 전투로 덮어쓰지 않는다. 이어하기는 저장된 빌드와 전투 ID를 유지하고 자동 강화 비용을 재소비하지 않는다.

초기 저장 실패와 재시도의 DOM 흐름, 비용/강화/층 롤백, 단일 저장, 이어하기, 읽을 수 없는 전투 보존 검사를 포함해 **102개 자동 검사 통과**. 정확한 원작 대조와 실기기 수용 조건은 위 미완료 표를 따른다.

전투 중 저장 공간 오류가 발생하면 입력을 초기화하고 시뮬레이션을 즉시 일시정지한다. 저장 재시도·메모리의 현재 전투 백업을 제공하며 복구 후 화면 터치로 재개한다. 자동 축복 처리 중 저장 실패도 같은 프레임의 후속 전투 갱신을 중단한다. 손상/작성자 충돌은 기존 저장 보호 화면을 사용한다. DOM 모형에서 저장 공간 오류 → 정지 → 재시도 → 입력 재개를 검사했다.

## 앱 이탈·미정산 백업 보완

숨김 상태에서는 visibilitychange 전달 순서와 관계없이 프레임 루프가 먼저 전투를 정지한다. blur·visibilitychange·pagehide는 동일한 중단 함수를 사용하며 진행/축복 선택 상태 모두 저장 후 정지한다. 복귀만으로 자동 재개하지 않는다. 숨김 프레임과 복귀 후 무입력 프레임에서 저장된 전투 시간이 증가하지 않는 DOM 모형 검사를 추가했다.

보상 저장 실패 시 내보내는 복구 JSON은 정상 정산과 같은 거래 함수를 사용한다. 재화·장비·자동 장착·전투 이력·정산 ID를 함께 포함하며 원본 프로필과 진행 객체는 변경하지 않는다. 백업을 불러온 뒤 원래 정산을 재시도해도 보상이 추가 지급되지 않는다. 진행 중 전투를 이 경로로 미리 정산할 수 없다.

전체 자동 검사 **104개 통과**, 구문/빌드 통과. 실제 기기 앱 전환·운영체제 종료·오프라인 검증을 수행한 것은 아니다.


## 초과 보관함 순서 안정화

장비 100개 초과 시 기본 보관함과 초과 보관함의 합치기 순서가 뒤집혀, 반복 정리·저장 불러오기에서 최근 획득품이 초과 보관함으로 밀리던 문제를 수정했다. 초과 보관품을 먼저 합치고 장착품을 보호한 뒤 최근 획득품을 기본 보관함에 유지한다. 장비 삭제나 재화 비용은 없다.

125개 장비의 정리·불러오기 5회 반복, 장착품 유지, 신규 보상 추가 후 126개 고유 장비 보존을 검사했다. 전체 **105개 자동 검사**, 구문 검사와 생산 빌드 통과. 원작 동일성·실기기 검증은 여전히 위 미완료 조건을 따른다.


## 자동 회피의 탄환 위험 예측 보완

자동 회피가 최대 0.3초의 예측 구간에서 탄환의 남은 수명과 첫 벽 충돌을 함께 검사하도록 수정했다. 실제 전투와 같은 선분-원 충돌 함수를 사용하며 기존 8단위 안전 여유는 유지한다. 도달 전 사라질 탄환이나 먼저 벽에 막힐 탄환 때문에 회피를 낭비하지 않고, 플레이어와 겹친 정지 탄환도 위험으로 인식한다.

수명이 짧은 탄환과 유효한 탄환, 같은 경로의 벽 유무, 겹친 정지 탄환을 비교하는 검사를 추가했다. **107개 자동 검사**, 구문·빌드 통과. 실제 기기 검증과 원작 대조는 미완료다.


## 연속 단계 전투 — 2026-10-12 최신 요구

이 절은 기존의 승리 후 결과 화면·다음 층 버튼 흐름보다 우선한다. 수문장 처치 시 보상 정산·추천 장비 자동 장착·다음 단계 전투 저장을 하나의 저장으로 확정하고 결과 화면 없이 즉시 진행한다. 탑 1~5층 이후 혼돈 1~20단계로 연결하며 20단계는 반복한다. 난이도는 선택한 설정을 유지한다. 각 단계는 스킬·레벨·경험치·현재 체력·쿨다운을 유지하며, 새 자동 장착 장비의 능력치 차이만 반영한다. 단계 사이 자동 강화 예산은 재소비하지 않는다.

전투 상단에 ‘전투 결과 확인’을 표시한다. 결과를 열면 현재 단계가 정지하며 최근 20개 단계의 보상·자동 장착 전후·획득품 상태·자동 선택 기록을 확인한다. 결과의 ‘전투 계속’은 현재 단계로 복귀하고 ‘전투 종료 · 로비로’는 진행 중 단계의 획득 보상도 정산한 뒤 로비로 이동한다. 패배하면 결과 화면으로 이동한다. 결과에는 수동 장착 버튼과 기본 수치만의 화살표 비교를 표시하지 않으며, 수동 장비 변경은 로비에서 한다.

저장 실패 시 다음 단계로 진행하거나 보상을 확정하지 않는다. 재시도는 1회 보상만 지급한다. 새 단계 전투 ID·장비·결과 기록이 함께 저장되므로 재접속 시 다음 단계 이어하기가 가능하다.

111개 자동 검사 및 구문·생산 빌드 통과. 다음 단계의 장비 적용, 중복·저장 실패 롤백, 혼돈 연결·20단계 반복, 결과 열기/복귀/종료와 종료 저장 실패를 검사했다. 실제 모바일 화면·터치 QA는 미완료다.


## 연속 전투 성장 상태 보존

단계 전환 시 새 전투의 적·지형·타이머·단계별 보상만 새로 준비하고, 직업·스킬 레벨·캐릭터 레벨·경험치·다음 레벨 필요 경험치·현재 체력·스킬/공격 쿨다운·자동화 설정을 이어간다. 기존 보유 장비·강화·옵션·소켓은 유지하며 새 보상 자동 장착을 적용한다. 능력치는 이전 장비와 새 장비의 차이만 반영하므로 체력 축복 효과를 중복 적용하거나 무료 회복시키지 않는다. 최대 체력이 줄면 현재 체력은 새 최대치까지만 유지한다.

정산한 단계 보상은 보관함/재료/재화에 남고 다음 단계 보상 목록은 비워 중복 지급을 막는다. 전투 종료 후 로비에서 새 도전을 시작할 때는 기존대로 축복을 초기화한다. 세 직업의 3회 연속 단계 이동과 저장 복원, 강화·소켓 장비 자동 장착 및 체력 축복 중복 방지를 포함해 **113개 자동 검사**, 구문·빌드가 통과했다.


## 연속 전투 복구 백업 — 2026-10-13

보스 처치 후 저장 실패 화면에서 내보내는 JSON도 정상 단계 전환과 같은 경로를 사용한다. 보상·자동 장착뿐 아니라 다음 단계, 스킬·레벨·경험치·체력·쿨다운을 함께 저장한다. 이전의 정산 전용 백업이 전투를 종료해 이어온 성장을 잃던 누락을 수정했다. 성능 기록도 보존한다. 패배 백업은 기존처럼 정산 후 전투 종료 상태이며, 진행 중 전투를 임의로 정산하지 않는다.

실패 → 백업 → 다음 단계 복원, 원본 프로필/전투/난수 불변, 중복 정산 방지, 5층에서 혼돈 연결 및 패배 처리를 검사했다. 전체 **115개 자동 검사**, 구문·생산 빌드 통과. 원작 자료 대조·실기기 검증은 기존 미완료 조건을 따른다.


## 공식 패치 대조와 기본 회복

공식 개발자 공지 대조는 research.md의 2026-10-13 절에 기록했다. 기본 3초 주기 최대 체력 1% 회복을 추가했다. 전설 장비 회복과 별도로 적용하고 주기를 저장·연속 단계에 보존한다. 회복 시점·최대치·패배 후 회복 금지·이전 저장 이관·잘못된 주기 거부를 포함해 **117개 자동 검사**, 구문·빌드 통과. 이번 적용이 원작의 모든 모드나 콘텐츠 구현 완료를 의미하지 않는다.


## 시작 스킬 자동 지급 — 2026-10-13

공식 1.1.0에서 확인한 3층 정복 후 시작 스킬 선택을 이동 전용 모바일 규칙에 맞춰 자동화했다. 4층 해금 상태에서 로비의 새 도전을 시작할 때 잿불·서리·번개·공전 중 하나를 기존 성향·가중치·사용자 우선순위·제외 정책으로 골라 1레벨 지급한다. 후보 4개와 자동 평가 방식은 독립 모바일 설계이며 원작의 후보 전체를 재현한 것은 아니다. 후보 모두 제외 시에는 기존 정책처럼 유효 후보로 대체하고 그 이유를 기록한다.

별도 비용과 실시간 선택창은 없다. 캐릭터 레벨·경험치는 증가시키지 않는다. 스킬과 이유는 처음 전투의 자동 선택 기록에 남으며, 연속 단계·이어하기에서는 기존 스킬만 유지하고 재지급하지 않는다. 빌드 편집 화면에 해금 조건과 규칙을 표시한다. 저장 실패 시 시작 스킬과 신규 전투를 함께 취소하므로 재시도로 추가 스킬을 얻지 않는다.

전체 **121개 자동 검사**, 구문 검사·생산 빌드 통과. 실제 기기 QA와 원작의 나머지 모드·전체 콘텐츠 대조는 미완료다.


## 새 도전 시작 경험치 — 2026-10-13

공식 1.1.0의 시작 경험치 조각 배치를 모바일 독립 수치로 구현했다. 새 도전의 시작 위치 주변 반경 80에 1포인트 조각 8개를 배치한다. 8개는 첫 레벨업에 필요한 모바일 초기 경험치이며 원작의 정확한 수량·배치 재현을 뜻하지 않는다. 기존 표시·흡입·수집·자동 축복 선택을 사용하므로 추가 입력을 요구하지 않는다.

새 전투를 저장할 때 함께 생성하며 저장 실패 시 모두 취소한다. 이어하기에서는 저장한 남은 조각만 복원한다. 연속 단계에서는 새로 생성하지 않는다. 이미 수집한 경험치·스킬은 기존 연속 전투 규칙대로 유지한다. 시작 안내에도 경험치 자동 수집을 표시한다.

세 직업 × 다섯 층의 배치·수집·자동 레벨업, 일부 수집 후 저장 복원, 단계 전환 중복 방지, 저장 실패 롤백을 포함해 **124개 자동 검사**, 구문·생산 빌드 통과. 실기기 검증과 원작 전체 콘텐츠 대응은 미완료다.


## 혼돈 단계 선택·구간 해금 — 2026-10-13

혼돈의 현재 선택 단계 `chaosDepth`와 최고 해금 단계 `chaosMaxDepth`를 분리한다. 탑 5층 정복 시 혼돈 1~5단계를 열고, 혼돈 5·10·15단계 정복 시 다음 5개 단계를 연다. 공식 1.1.0의 5단계 구간 해금 방향을 모바일 20단계 범위에 적용한 독립 규칙이다. 해금된 구간 안에서는 중간 단계를 건너뛰거나 낮은 단계로 돌아가 파밍할 수 있다.

로비의 난이도·혼돈 설정에서 시작 단계를 무료 선택한다. 잠긴 선택은 UI에서 비활성화하고 정규화에서도 최고 해금 단계까지만 허용한다. 낮은 단계 선택·패배로 최고 해금 기록을 낮추지 않는다. 자동 연속 진행은 선택했던 최고치가 아니라 방금 클리어한 단계 +1부터 이어지며, 20단계는 반복한다. 실행 중 전투는 그대로 두고 설정은 새 도전부터 적용한다.

이전 저장은 기존 혼돈 진행 단계를 포함하는 5단계 구간으로 이관한다. 예: 기존 8단계는 선택 8/최고 해금 10. 신규 필드가 있는 저장은 명시된 해금 한도를 유지한다. 단계 정산·해금·다음 전투 저장은 기존 원자적 거래를 사용한다.

전체 **128개 자동 검사**, 구문·빌드 통과. 저장 이관, 잠긴 단계 제한, 5단계 경계 해금, 이전 단계 재도전 후 연속 진행, 패배·저장 실패, UI 선택 저장을 검사했다. 실기기 검증·원작 전체 모드 대응은 미완료다.


## 연속 전투 전체 빌드 기록 — 2026-10-13

단계 종료 기록에 그 시점의 전체 스킬 레벨을 저장한다. 단계별 자동 선택 로그는 그대로 분리해 유지한다. 이전 단계에서 얻은 스킬을 유지한 채 새 선택 없이 끝낸 경우에도 결과·전투 기록에서 전체 빌드를 확인하고 다음 도전의 우선순위 템플릿으로 가져올 수 있다.

가져오기는 해당 직업을 선택하고 스킬 레벨 ×2(상한 10)를 우선순위로 설정하며 제외 목록을 비운다. 스킬을 무료 지급하거나 진행 중 빌드를 교체하는 기능은 아니다. 전체 빌드가 없는 옛 기록은 확인 가능한 단계별 선택만 사용하고 화면에 이를 표시한다. 알 수 없는 스킬·다른 직업 스킬·잘못된 레벨은 제외하며 빈 기록은 현재 설정을 덮어쓰지 않는다. 저장 실패 시 기존 편집 설정을 유지한다.

상속된 스킬의 정산·불러오기·템플릿 적용, 옛 기록 호환, 잘못된 데이터, 빈 기록, 저장 실패, UI 연결을 포함해 **131개 자동 검사**, 구문·생산 빌드가 통과했다. 원작 전체 콘텐츠와 실기기 검증은 기존 미완료 항목을 따른다.

## 2026-10-13 승리 시 남은 경험치 회수

보스 처치 후 즉시 다음 단계로 넘어가면서 바닥의 경험치 포인트(보스 드롭 포함)가 사라지던 경로를 수정했다. 승리 사본에서 남은 포인트를 회수하고 레벨업 자동 선택을 처리한 뒤 결과 기록·자동 장착·다음 단계 저장을 하나의 원자적 변경으로 확정한다. 저장 실패 시 원본 전투·난수·경험치는 변하지 않으며, 재시도·복구 백업·중복 호출에서도 한 번만 반영한다. 실패/수동 종료 시 미수집 경험치를 보상으로 지급하는 변경은 아니다.

continuous.test.js에 실제 보스 드롭과 원거리 포인트의 레벨업/기록/이어하기, 저장 실패·재시도·재호출·백업 일관성 검사를 추가했다. 전체 133개 검사 및 구문·빌드 확인. 실기기 수용과 원작 전체 대응의 미완료 상태는 유지한다.


## 2026-10-13 최대 스킬 이후 다중 레벨업 회복

모든 사용 가능 스킬이 최대 레벨일 때 여러 레벨업을 한 번에 처리하면 회복 25가 한 번만 적용되던 문제를 수정했다. 대기 중인 레벨 수만큼 25씩 회복하고 대기 수를 지워, 경험치를 나눠 받거나 승리 때 모아 받아도 동일하게 적용한다. 최대 체력 한도는 유지하며 처리할 레벨이 없으면 회복하지 않는다. 이는 모바일의 기존 최대 스킬 대체 보상 규칙을 일관되게 적용한 것이며 원작 수치 대응 주장이 아니다.

capped-growth.test.js에서 3직업의 일괄/분할 경험치, 마지막 스킬과 잔여 레벨, 체력 상한·복원 후 재호출, 승리 저장 실패·백업·재시도·중복 호출을 확인한다. 전체 137개 검사, 구문 검사 및 빌드 통과. 원작 전체 콘텐츠와 실기기 수용 미완료 항목은 그대로 남아 있다.


## 2026-10-13 혼돈 기록 식별 일관성

최근 전투 기록과 성능 기록이 혼돈의 단계 대신 배경 층만 표시하던 문제를 수정했다. 결과·최근 기록·성능 기록·진행 중인 결과의 일시정지 안내·새 도전의 기존 전투 종료 안내에서 동일한 난이도/탑 층/혼돈 단계 표기를 사용한다. 진단 JSON에도 전투 ID, 모드, 깊이, 난이도, 생성 시각을 포함해 반복 혼돈 전투를 구분할 수 있다. 구형 기록의 누락된 난이도·모드는 기존 동작에 맞춰 일반·탑으로 표시하며 유효하지 않은 단계 수치는 ‘미상’으로 표시한다.

## 2026-10-13 연속 단계 도전 설정 고정

저장된 전투가 있는 상태에서 로비 난이도·모드·시작 단계를 바꾸면 이어하기 이후 다음 단계가 새 로비 설정으로 생성될 수 있던 문제를 수정했다. 다음 전투는 진행 중인 전투의 난이도와 탑/혼돈 순서에서 계산하며, 로비 난이도 선택 자체는 보존해 새 도전에 반영한다. 탑 5층 → 혼돈 1단계, 혼돈 20단계 반복 규칙은 유지한다.

## 화면 회전 중 전투 보호 — 2026-10-14

실제 화면 너비·높이가 바뀌면 진행 중 전투를 일시정지·저장하고 조이스틱 입력을 해제한다. 새 화면에서 다시 터치해야 전투를 재개한다. 크기가 같은 resize 이벤트는 이동을 끊지 않는다. 투기장 미리보기는 정지만 하고 기존 일반 전투 저장을 덮어쓰지 않는다.

DOM 모형에서 가로·세로 전환, 기존 손가락 이동 무효화, 정지 중 전투 갱신 차단, 새 터치 재개, 동일 크기 이벤트, 미리보기 저장 격리를 확인했다. 실제 iOS·Android 화면 회전과 터치 검증은 미완료다.
