# 모바일 전용: 이동 입력·자동 판단·유료 재설정 설계

개정: 2026-10-11 KST
상태: 자동 전투 1차 구현. 8방향 입력·자동 축복·회피·폭발·4종 성향·선택 이유 기록·앱 복귀 정지가 구현되었다. 장비 잠금·자동 장착·이전 장비 복원·초과 보관함·강화 유료 재설정·분해 복원·v2 저장 이관과 최근 20개 거래 기록이 구현되었다. 다중 옵션 변경·세부 빌드 우선순위 편집·동시 탭 쓰기 제어는 후속 작업이다.
최상위 요구: 전투 중 플레이어 입력은 이동 방향키만 받는다. 나머지 실시간 판단은 자동으로 수행한다. 수집 아이템과 자동 선택은 전투 후 확인·재설정·커스텀이 가능해야 한다.

## 1. 변경된 제품 목표

모바일 전용으로 전투의 조작과 성장 전략을 분리한다. 전투 중에는 이동에 집중하고, 전략은 전투 전후의 빌드 편집기로 관리한다. 원작은 콘텐츠·성장 깊이·시청각의 벤치마크로 유지하되 수동 스킬 선택과 입력 방식은 이 요구에 맞춰 변경한다. 이전 문서의 ‘자동화 보류’와 ‘스킬 직접 선택 유지’보다 이번 요구를 우선한다.

‘자동 최적 선택’은 현재 상태와 설정한 목표에 대한 점수 기반 최선 후보 선택으로 정의한다. 미래 드롭이나 모든 빌드의 전역 최적해를 알고 있다는 뜻은 아니다. 판단 이유와 정책 버전을 기록하고 실제 전투 결과로 개선한다.

## 2. 화면과 입력

| 시점 | 사용자 입력 | 자동 동작 |
| --- | --- | --- |
| 로비 | 직업·층·빌드·자동화 성향 편집, 전투 시작 | 기본 성향과 유효한 장비 추천 |
| 전투 | 이동용 방향키만 | 조준·공격·회피·폭발·스킬 선택·경험치 수집·획득품 보관 |
| 레벨업 | 입력 요구 없음 | 후보 평가 → 선택 → 적용 → 작은 안내 기록, 모달 없음 |
| 종료 | 결과 확인·커스텀·재설정·재도전 | 보상 1회 정산, 장비 추천과 선택 기록 생성 |
| 앱 이탈·복귀 | 복귀 후 이동키 입력으로 계속 | 이탈 시 정지·저장, 복귀 시 방향키를 누르기 전까지 정지 |

8방향 D-pad를 기본으로 한다. 상하좌우 4개 누름 영역과 대각선 입력 조합을 제공하며 대각선 속도는 정규화한다. 다중 포인터의 방향 기여를 각각 추적하고 손을 떼거나 캡처가 해제되면 해당 입력을 제거한다. 터치 영역은 최소 44 CSS px, 왼손/오른손 배치와 크기는 로비 설정에서 변경한다. 가상 조이스틱·전투용 회피·폭발·스킬 선택·일시정지 버튼·키보드 전투 조작은 모바일 제품 UI에서 제거한다.

전투 종료·축복 선택·장비 드롭은 화면을 가리는 모달을 띄우지 않는다. 자동 선택 안내는 전장 바깥 작은 상태줄에 잠시 표시하며 결과 화면에서 전체 기록을 읽을 수 있다. 로비·결과의 편집 버튼은 실시간 전투 입력 제한의 적용 대상이 아니다.

자동 회피는 방향키를 대신 눌러 길찾기하는 기능이 아니다. 사용자가 입력한 방향을 우선하고 짧은 회피 동작만 실행한다. 고정된 벽을 넘거나 원하지 않는 경로로 장시간 이동시키지 않는다.

## 3. 자동화 규칙

| 판단 | 기본 규칙 | 보호 규칙 |
| --- | --- | --- |
| 공격·조준 | 현재 무기·스킬의 사거리 안에서 위협·명중 가능성 평가 | 죽은 적·벽 뒤 목표 제외, 급격한 목표 흔들림 방지 |
| 회피 | 예고된 공격의 예상 명중과 접촉 위험이 임계값 이상이면 발동 | 입력 방향 우선, 그 방향이 위험하면 짧은 안전 방향 선택, 충돌 검사·쿨다운 준수 |
| 폭발 | 주변 위협 또는 보스에게 유효한 피해가 기준 이상이면 사용 | 적이 없거나 무적 상태인 목표에 낭비하지 않음 |
| 레벨업 선택 | 유효 후보 중 성향·생존·피해·시너지·성장 점수가 가장 높은 후보 | 상한·직업 제한·잠금·사용자 제외 목록 준수 |
| 경험치 | 기존 흡입 범위 안에서 자동 수집 | 플레이어를 아이템 위치로 자동 이동시키지 않음 |
| 장비 획득 | 모두 보관 또는 안전한 임시 보관함으로 이동 | 가방 한도로 아이템 삭제·자동 분해하지 않음 |
| 장비 착용 | 결과 정산 후 부위별 후보 조합 평가, 자동 장착 | 잠금 부위 유지, 전투 도중 교체하지 않음, 모든 아이템 보존 |
| 강화·재설정 | 로비에서 사용자가 설정한 배분 계획 적용 | 기본값에서는 재화를 자동 소비하지 않음 |

자동 판단이 잘못돼도 플레이어에게 추가 비용이 발생하지 않는 안전장치를 먼저 구현한다. 보상은 결과 화면을 열어야 정산되는 방식이 아니라 종료 상태에 들어가는 시점에 저장과 함께 정산한다. 다음 전투를 자동 시작하거나 다음 층으로 강제 진입하지 않는다.

## 4. 선택 점수와 커스텀

자동 선택 성향은 균형(기본), 생존, 공격, 파밍, 직접 편집 5종이다. 직접 편집에서는 스킬 우선순위·제외 목록·장비 잠금·선호 속성·회피 보수성·폭발 사용 기준을 설정한다. 성향 및 우선순위 편집·보유 장비 교체·프리셋 변경은 무료다.

후보 점수 초안:

`점수 = 피해 개선 × 가중치 + 생존 개선 × 가중치 + 수집 개선 × 가중치 + 장비/스킬 시너지 + 사용자 우선순위 - 중복/상한/실효성 손실`

각 개선값은 같은 기준으로 정규화한다. 체력 25% 이하일 때 생존 가중치를 높이고, 보스 단계에서는 수집 가중치를 낮춘다. 고등급이라는 이유만으로 장비를 선택하지 않고 실제 피해·유효 체력·고유 효과를 비교한다. 사용자 잠금·제외는 점수보다 먼저 적용한다. 모두 제외된 후보에는 ‘직접 제외로 후보 없음’ 기록을 남기고 유효한 기본 후보로 안전하게 대체한다. 최대 레벨 등 엔진 제약을 무시하는 대체는 허용하지 않는다.

동점은 사용자 우선순위 → 기존 빌드 시너지 → 안정된 콘텐츠 ID 순으로 결정한다. 판단용 난수와 드롭 난수를 분리하고, 자동 판단 때문에 드롭 결과가 바뀌지 않도록 한다. 영구 성장 재화까지 자동 최적 배분하려면 로비에서 예산·보존 잔액을 별도 설정해야 하며 기본 예산은 0이다.

## 5. ‘되돌리기’의 정확한 범위

| 대상 | 가능한 변경 | 비용·제한 |
| --- | --- | --- |
| 자동 장착 | 이전 장비로 복원, 원하는 보유 장비 장착 | 무료. 보유 아이템 유지·장비 잠금 지원 |
| 다음 전투의 자동 선택 | 성향·우선순위·제외·프리셋 편집 | 무료. 다음 전투 시작 시 스냅샷 고정 |
| 영구 강화 배분 | 투자한 성장 포인트·강화 비용을 회수해 재배분 | 재설정 수수료 차감 후 투자 원금 반환. 외부 보상은 반환하지 않음 |
| 보유 아이템 옵션 | 잠그지 않은 옵션 재추첨 또는 허용된 옵션으로 지정 변경 | 사전 표시한 재화 소비. 등급·아이템 ID·소유권은 유지 |
| 수집 아이템 분해·판매 | 최근 거래를 취소하고 원본 복원 | 판매 보상 전액 반환 + 수수료. 반환 재화 부족·후속 사용 시 취소 불가 |
| 완료된 전투의 스킬 선택 | 선택 이력을 빌드 템플릿으로 편집·저장 | 종료된 전투 결과는 소급 변경하지 않음. 다음 전투에서 적용 |
| 진행 중 전투의 선택 | 현재 체력·피해·시간·보상과 분리된 변경 금지 | 전투 중 유료 편집 UI 없음. 로비로 돌아온 뒤 현재 런 종료·정산 후 다음 런 계획 편집 |

런 내 축복은 현재처럼 전투 종료 후 초기화한다. 따라서 종료된 축복을 환불 대상으로 삼아 재화를 소비시키지 않는다. 사용자 마음대로 커스텀하는 범위는 보유·해금 콘텐츠 안에서의 배치·우선순위·옵션 조정이며 미획득 아이템 생성이나 잠긴 콘텐츠 획득은 아니다.

‘되돌리기’는 재설정·거래 취소이고 전체 세계 시간 되감기는 아니다. 보스 처치·클리어·경험치·드롭을 보존한 채 과거 상태로 복귀하여 보상을 반복 지급할 수 없다. 확정된 드롭의 결과를 새로고침으로 재추첨하지 않는다.

## 6. 재화와 가격 초안

기존 파편을 1차 구현의 공통 재화로 사용한다. 결제 상품이나 새로운 유료 통화는 추가하지 않는다. 자동 전투와 선택에는 비용을 부과하지 않고, 자원 재배분·옵션 변경·분해 복구만 비용이 발생한다.

첫 튜닝값(원작 수치 아님): 영구 강화 전체 재설정 20파편, 아이템 옵션 재추첨 `10 + 등급 인덱스 × 10`파편, 지정 옵션 변경은 재추첨 비용의 2배, 분해 취소는 기존 지급 재화 전액 + 10파편. 옵션 잠금 추가 비용은 초기 버전에서 0으로 두고 잠긴 옵션은 변경 대상에서 제외한다. 모든 옵션이 잠기면 변경 버튼을 비활성화하고 비용을 받지 않는다.

확정 전 화면에서 변경 전후·반환 원금·수수료·차감 후 잔액을 표시한다. 취소 시 차감 0, 성공 1회만 차감, 실패 시 원상 복구다. 재화 부족이어도 자동 플레이·보유 장비 교체·무료 빌드 편집은 가능하다. 테스트 플레이 수입을 측정한 뒤 가격을 조정하며, 반복 이용 시 가격이 몰래 증가하는 규칙은 두지 않는다.

## 7. 저장과 거래 구조

새 프로필 스키마 v2:

- `wallet`: 현재 재화와 거래 원장.
- `automation`: 성향·가중치·우선순위·제외·잠금·정책 버전.
- `presets`: 직업별 장비와 자동 선택 계획.
- `inventory`: 고유 ID·옵션·잠금·아이템 개정 번호.
- `overflow`: 가방 초과 획득품. 결과 정산에서 절대 버리지 않음.
- `decisionLog`: 후보·선택·주요 점수·선택 이유·시간·정책 버전.
- `transactions`: 작업 ID·유형·비용·변경 전후·상태·참조 보상 ID.
- `run`: 자동화 설정 스냅샷·난수 상태·정산 ID·자동 처리 대기 수준.

현재 v1 저장의 파편·장비·강화·해금·진행 중 런을 보존해 이관한다. 강화 투자 원금은 기존 비용 공식으로 재구성하고 실제 환급은 같은 공식·상한으로 제한한다. 과거 분해 이력은 없으므로 v2 이전 분해 아이템은 복원할 수 없다고 표시한다.

거래는 잔액·아이템 개정 번호 확인 → 변경 전 상태 보관 → 비용과 결과를 하나의 프로필 변경으로 확정 → 저장 성공 표시 순서다. 저장 실패 시 메모리 상태도 복구한다. 같은 작업 ID 재시도는 추가 차감·추가 아이템 없이 기존 결과를 돌려준다. 옵션 추첨 결과도 거래 ID에 고정한다. 다른 탭에서 동시 수정되면 활성 플레이 탭 하나만 쓰기 권한을 유지한다. 로컬 저장은 기기 내 데이터이며 서버 검증·클라우드 동기화를 제공하지 않는다.

활동 기록은 최근 20개 전투, 각 전투 자동 선택 최대 200개, 거래 취소용 원본 최근 20개 거래로 제한한다. 보관 범위를 벗어나 취소할 수 없는 거래는 UI에 명시한다. 거래를 취소한 이후 해당 아이템을 재분해해도 순재화가 늘어나지 않아야 한다.

| `showGear`, `showUpgrades` | 무료 커스텀·잠금·유료 재설정·비용 미리보기 |
| `loadProfile`, `save`, `Game.restore` | v2 이관·거래 원자성·설정 스냅샷·난수 상태 복원 |
| `index.html`, `styles.css` | 전투 하단 D-pad만 표시, 상태 안내·로비 편집 UI |
| 새 `automation.js` | 순수 후보 평가, 위험 예측, 목표 선택, 판단 로그 |
| 새 `transactions.js` | 비용 산정·재설정·옵션 변경·거래 취소·중복 방지 |

자동화 정책을 DOM과 분리해 시뮬레이션에서 검증한다. 레벨업 판정 시 현재 후보 하나를 자동 적용하고 연속 레벨업을 순차 처리한다. 화면은 선택 대기 상태에 머물지 않는다. 비용을 쓰는 작업은 자동 선택 처리 경로와 분리한다.

## 9. 구현 순서와 완료 조건

1. 이동 전용 전투: D-pad, 자동 축복, 자동 회피·폭발, 입력 취소·복귀 동작. 조건: 시작부터 결과까지 방향키 외 입력 없이 완주 가능.
2. 자동 판단 커스텀: 성향·우선순위·잠금·결과 기록. 조건: 같은 상태와 설정에 같은 선택, 제외·상한 준수, 이유 표시.
3. 보관·장비: 자동 장착·복원·초과 보관함. 조건: 잠금 장비 유지, 수집품 유실 0, 무료 복원이 정확히 이전 장비로 돌아감.
4. 재화 재설정: v2 이관·원장·강화 재배분·거래 취소. 조건: 중복 실행·저장 실패·새로고침·잔액 부족에서 자원 보존.
5. 다중 옵션 아이템: 옵션 정의를 먼저 확정한 뒤 재추첨·지정 변경. 조건: 잠금 옵션 불변, 허용 옵션 범위·최대치 준수, 비용 중복 차감 없음.
6. 모바일 검증: iPhone/Android 방향 입력·동시 터치·배경 복귀·오프라인·최대 부하. 조건: 전투 중 선택 팝업·추가 조작 없이 안정적으로 진행.

옵션 변경은 현재 단일 수치 장비에 곧바로 붙이지 않고 다중 옵션 모델 이후 구현한다. 모든 자동화·가격 규칙은 원작 확인 항목과 분리된 사용자 지정 모바일 요구다. 벤치마크 규칙과 달라졌다는 이유로 이전 수동 UI로 되돌리지 않는다.

## 10. 필수 검증 시나리오

- 3직업을 방향키만 입력해 레벨업·보스·결과까지 진행, 자동화가 주기적으로 불필요한 스킬을 소비하지 않는지 확인.
- 연속 레벨업·후보 전부 최대치·제외 목록·동점·사용자 장비 잠금 검증.
- 회피 중 입력 방향 변경·벽 근처·입력 없음·위험 방향·자동 무적·쿨다운 검증.
- 앱 이탈·회전·터치 취소 시 이동 정지, 복귀 전 시간과 체력 불변.
- 100개 초과 아이템·동일 부위 보상·강화 장비·잠긴 아이템이 삭제되지 않는지 확인.
- 재설정 전후 투자 원금·잔액 보존, 옵션 변경 및 거래 취소 2회 호출·저장 실패·동시 탭 충돌 검증.
- v1 저장과 진행 중 런 이관, 기존 파편·장비·해금 보존. 비용과 보상이 중복 적용되지 않음.
- 준비 단계의 무료 커스텀과 유료 변경이 UI에서 구분되고 지불 후 실제 결과가 미리보기와 일치.

### 2차 구현의 제한

현재 장비는 부위별 단일 능력치이므로 자동 장착은 같은 부위에서 수치가 더 높은 보유 장비를 선택한다. 이전 장비 복원은 아직 보유한 아이템만 복원하며 분해한 장비는 분해 복원을 먼저 해야 한다. 거래 중복 방지는 최근 20개 기록 범위이며 여러 탭에서 동시에 플레이하거나 거래하지 않아야 한다. 기록이 없는 과거 분해는 복원할 수 없다.
