# BABEL · 잿빛 탑

모바일 우선 서바이버 액션 RPG의 플레이 가능한 PWA 프로토타입입니다.
벤치마크는 NANOO의 [Tower of Babel: Survivors of Chaos](https://store.steampowered.com/app/2665680/Tower_of_Babel_Survivors_of_Chaos/?l=koreana)입니다. 원작의 공식 모바일 포팅이 아니며, 원작 이미지·음원·코드·캐릭터 에셋을 포함하지 않습니다.

## 실행

Node.js 20 이상, Python 3가 있으면 외부 패키지 설치 없이 실행할 수 있습니다.

```sh
npm run check
npm test
npm run build
npm start
```

브라우저에서 `http://localhost:8080`을 여세요. 같은 네트워크의 휴대폰에서는 PC의 LAN IP와 8080 포트를 사용합니다. 오프라인 캐시와 홈 화면 설치는 HTTPS 배포 또는 localhost에서 지원됩니다. `index.html`을 파일로 직접 열면 ES 모듈과 서비스 워커가 동작하지 않을 수 있습니다.

현재 동작과 미완료 수용 조건은 [현재 설계 기준](docs/current-design.md)을 따릅니다.

## 구현 기능

- 세로 화면 우선 반응형 UI, 노치 안전 영역, 가로 화면 대응.
- 기사 / 술사 / 추적자: 근접 베기, 광역 투사체, 원거리 속사.
- 5개 층 순차 해금. 각 층 90초 웨이브 후 최대 60초 보스전.
- 화면 어디든 터치한 위치에서 시작하는 360도 가상 조이스틱으로 이동 방향·속도 조절. 공격·조준·회피·폭발·축복 선택 자동 처리.
- 경험치 수집, 공통 9종·직업 전용 6종 축복의 후보 평가·자동 선택, 선택 이유 기록.
- 일반 / 돌격 / 원거리 / 정예 / 보스 적, 보스 장판 예고와 방사형 탄막.
- 15처치마다 체력 회복, 보스 진입 시 체력 20% 회복과 일반 적 정리.
- 정예 장비 드롭, 보스 희귀 이상 보상, 5개 등급과 무작위 능력치.
- 무기 / 방어구 / 부적 자동 장착·부위 잠금·무료 이전 장비 복원, 초과 보관함.
- 장비 분해 기록 및 지급 파편 반환 + 10파편 수수료로 복원.
- 영구 강화 투자 원금 환급·20파편 재설정 수수료, 저장 실패·최근 거래 중복 처리 방지.
- 공격력 / 체력 / 파편 보상 영구 강화, 패배 시에도 획득 보상 정산.
- 5초 간격 전투 저장, 저장 후 로비로, 새로고침 후 전투 이어하기.
- 앱 전환·포커스 이탈 시 자동 정지, 왼손 모드, 절전 화질, 효과음 설정.
- 무료 빌드 편집: 스킬 우선순위·제외·가중치·회피/폭발 기준·선호 옵션.
- 직업별 3개 프리셋·최근 20개 전투 기록과 다음 빌드 템플릿.
- 다중 옵션 9종·2~3슬롯, 잠금·유료 재추첨·지정 변경과 결과 미리보기.
- 강화 자동 사용 예산·보존 잔액·순서, 기본 예산 0.
- 상단 결과 확인·일시정지·전투 계속·종료, 전체 스킬 빌드 이력과 템플릿.
- JSON 저장 백업·복구, 전투와 드롭 난수 분리·복원, 승리 백업에 다음 단계 성장 상태 보존.
- 큰 글씨·피해 숫자·효과 불투명도·조이스틱 크기 설정.
- 장비별 강화 5단계·원금 환급, 전설 고유 효과 3종, 장비 외형 레이어.
- 보석·룬 5종 × 3등급, 희귀 이상 소켓, 회수·교체와 연금술 합성·종류 변환.
- 일반·어려움·악몽, 직업 공통 해금과 20단계 혼돈 던전.
- 직업별 전용 스킬 2종씩·선행 축복 조건, 층별 적 구성과 보스 패턴.
- 충돌·우회·시야 차폐가 있는 5개 지형, 장애물을 넘지 않는 자동 회피.
- 층별 합성 배경 음악, 효과음·음악 개별 설정.
- 빌드별 모듈·스타일과 SHA-256 검증 오프라인 캐시, 로비에서 저장 후 업데이트.
- 손상 저장 원본 보존·내보내기·백업 복구, 미래 저장 버전 자동 초기화 방지.
- iOS/Android 설치용 PNG 아이콘. 런타임 외부 서비스 요청 없음.

모바일 전용 전투 입력: 화면의 가상 조이스틱. 로비 설정에서 균형·생존·공격·파밍 성향을 선택합니다. 앱에서 이탈하면 자동 일시정지하며 복귀 후 조이스틱을 터치하면 계속합니다. 키보드 전투 조작은 제공하지 않습니다.
보스 처치 후 다음 단계로 자동 진행하며 스킬·레벨·경험치·체력·쿨다운·장비 상태를 유지합니다. 전투 축복은 로비에서 새 도전을 시작할 때만 초기화됩니다. 저장은 브라우저 localStorage이며 기기 간 동기화는 없습니다. Web Locks로 저장 작성자 탭을 하나로 제한합니다. 다른 탭은 저장 보호 모드로 열립니다. 잠금 기능이 없는 브라우저는 진행할 수 없으며 백업 내보내기를 제공합니다.

## GitHub Pages 배포

저장소: `https://github.com/jflakeee/towerofbabel.git`

1. 소스를 `main` 브랜치에 push합니다.
2. GitHub 저장소 **Settings → Pages → Source → GitHub Actions**를 선택합니다.
3. `.github/workflows/pages.yml`이 구문 검사, 테스트, 정적 빌드를 실행한 후 Pages에 배포합니다.
4. Actions의 배포 작업에서 실제 URL을 확인합니다. 기본 예상 주소는 `https://jflakeee.github.io/towerofbabel/`입니다. 이 README의 예상 주소만으로 배포 성공을 뜻하지는 않습니다.

프로젝트 경로 아래에서 실행되도록 모든 자원 경로는 상대 주소입니다. 다른 정적 호스팅은 `npm run build` 결과인 `dist/`를 게시하면 됩니다.

## 범위

현재는 독립 프로토타입입니다. 네이티브 APK/IPA, 원작 전체 콘텐츠, 서버 계정, 과금, 클라우드 저장, 완전한 아이소메트릭 월드, 원작의 정확한 에셋과 콘텐츠 목록은 확보하지 못했습니다. 모바일 독립 콘텐츠로 장비 외형 레이어와 층별 충돌 장애물·우회 이동·벽 차폐를 구현했습니다. 적은 바닥 좌표에서 움직이고 그래픽에 입체 표현을 사용합니다.

리서치는 공개 웹 자료를 교차 검토했습니다. 유튜브 전체 영상·자막을 확보하지 못해 프레임 단위 관찰이나 영상 내용의 완전한 검증을 주장하지 않습니다. 상세 한계는 [분석 문서](docs/research.md)를 참고하세요.

오프라인 사용 전 설정에서 **오프라인 준비 완료**를 확인하세요. 새 버전이 준비되면 설정의 **저장하고 새 버전 적용**을 사용합니다. 실제 모바일 설치와 터치·성능 검증은 아직 미완료입니다.

수문장 클리어 시 추천 장비를 자동 장착합니다. 잠근 부위는 유지하며 기존보다 점수가 높은 장비만 교체합니다. 패배 종료에도 자동 장착하며 이전 끄기 설정은 적용하지 않습니다. 결과 화면에서 장착 중인 장비를 확인하고 장비 메뉴에서 이전 장착으로 복원할 수 있습니다.

## 2026-10-12 설계 수용 보완

유료 변경의 확정 전 잔액/결과 확인, 무료 커스텀의 저장 실패 보호, 자동 장착 전후 이력, 축복 후보 점수·정책 표시, 설정의 플레이 성능 진단과 JSON 내보내기를 추가했습니다. 90개 자동 검사를 통과했습니다. 현재 수용 상태와 실기기 점검 순서는 [구현 대응표](docs/implementation-status.md)를 참고하세요. 원작 완전 동일성과 실기기 검증은 미완료입니다.

후속 전투 검증: 고속 탄환의 이동 경로 충돌, 가까운 순서의 관통, 벽 차폐·탄환 수명, 승리 후 추가 피해/보상 차단, 축복 직업/상한 재검사를 보완해 자동 검사 97개를 통과했습니다.

적 처치 경험치 포인트의 화면 표시를 복구했습니다. 모든 스테이지 종료 후 추천 장비 자동 장착을 적용하며 자동 검사 98개를 통과했습니다.
